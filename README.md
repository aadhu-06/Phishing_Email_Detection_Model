# Phishing_Email_Detection_Model
Overview

Phishing Email Detection Model is a machine learning project that detects whether an email is Phishing or Safe. It analyzes email content, extracts important features, and classifies the email using Logistic Regression. The model is trained on phishing and legitimate email datasets and evaluated using accuracy and confusion matrix.

Features:

Detects Phishing and Safe emails.

Uses Machine Learning (Logistic Regression).

Performs text preprocessing and URL detection.

Extracts features using TF-IDF Vectorizer.

Displays Accuracy Score and Confusion Matrix.

Allows users to test new email content.

Saves the trained model as model.pkl.

Technologies Used Python, Pandas, Scikit-learn, Joblib, Regular Expressions (Regex)

Conclusion : The Phishing Email Detection Model successfully identifies whether an email is Phishing or Safe using machine learning techniques. By analyzing email content and extracting important features, the model helps detect suspicious emails and improve email security. The project demonstrates the practical use of Scikit-learn, TF-IDF, and Logistic Regression for cybersecurity applications.
